Sudoku on Stream

A Sudoku your Twitch chat solves together. Viewers type a cell and a number, like B7 4. Right answers land on the board in their chat colour, and points go to a live leaderboard.

SET IT UP

1Get your link

Type your Twitch channel name and pick how you want to play. The links update as you go. You can change all of this later, from chat or the control page.

More options

A prefix like ! means chat types !B7 4. Use it if normal chat keeps setting off moves. Hint 0 turns automatic hints off.

🎮 Game (the board on stream)
Type your channel name above
🎛️ Control page (optional, for you only)
▶ Test it in your browser

The test opens a typing box at the bottom of the side panel, so you can play as chat yourself before going live.

2Add the game to OBS

  1. In your scene, click + under Sources and pick Browser.
  2. Paste the Game link into the URL box.
  3. Set Width 1920 and Height 1080, then click OK.

That's it: the board shows ● reading #yourchannel at the bottom once it's listening. Streamlabs Desktop works the same way (Browser Source).

3Add the control page (optional)

Start / Stop, a difficulty slider, puzzle type, hints, new puzzle and score resets, all as buttons. You can also make your own puzzles there: type them into a grid, and it checks they have exactly one solution before chat plays them.

  1. Make a new scene called something like Sudoku Control that you never switch to on stream.
  2. Add a Browser source there with the Control page link, size 1920 × 1080.
  3. Untick Shutdown source when not visible.
  4. Right-click the source → Interact to use the buttons.

Both sources must come from the same place (both from tavernworks.dev, or both from your download), so they can talk to each other.

4Tell chat how to play

The side panel already explains it, but here's the short version for your !sudoku command:

Help solve the Sudoku! Type a cell then a number, like B7 4. Right answers +10, finish a row/column/box +5, wrong −2. Notes: B7?35 pencils in 3 and 5, A1A3?678 does several cells at once.
RATHER RUN IT YOURSELF?

The links above use the copy hosted here, which always has the latest version. If you'd rather run it from your own computer (it works with no internet apart from Twitch chat), download it instead:

⬇ Download sudoku-on-stream.zip
  1. Unzip it somewhere it can stay, like Documents.
  2. Double-click index.html. The setup screen opens; fill it in and click Copy URL.
  3. In OBS, add a Browser source, untick Local file, paste the URL and set 1920 × 1080.
  4. For the control page, add control.html the same way, as a file:/// URL from the same folder.

Scores and the puzzle in progress are saved inside OBS, separately for the hosted and downloaded copies, so pick one and stick with it.

HOW CHAT PLAYS

Moves

CHAT TYPESWHAT HAPPENS
B7 4Puts a 4 in row B, column 7. b7=4 and B74 work too.
A1 5 C3 2Up to 3 moves in one message
B7?35Pencils small 3 and 5 into B7 (never scored)
A1A3?678Pencils 6, 7 and 8 into A1 and A3. List up to 9 cells before the ?; A1 A3?678 works too.
B7?-3Rubs out the 3
B7?xClears B7's notes (A1A3?x clears both)

Scoring

EVENTPOINTS
Right answer+10
Finish a row, column, box or extra region+5 each
Last cell of the puzzle+10
Wrong answer−2 and a 3 s timeout

No right answer for 60 s and a cell is revealed; the bar under the title counts down to it. Solve it and an MVP screen shows before the next puzzle.

MOD COMMANDS

Only the broadcaster and moderators can use these, typed in chat:

COMMANDWHAT IT DOES
!sudoku newNew puzzle now. Add a type and/or level: !sudoku new windoku 9
!sudoku level 12Fixed level (1–20) for upcoming puzzles
!sudoku level autoAdaptive difficulty again (optionally auto 8 to restart at 8)
!sudoku level rotateCycle through every level, 1 → 20
!sudoku variant diagonalPuzzle type: classic, diagonal, windoku, centerdot, asterisk or mix
!sudoku stop / startPause and resume; the clock and hint countdown freeze
!sudoku hintReveal one cell
!sudoku clearnotesWipe every viewer note
!sudoku resetscoresWipe the all-time leaderboard
DIFFICULTY

There are 20 levels, from Beginner to Nightmare. Every puzzle is graded by a solver that thinks like a person, so the level is about how hard it is to reason through, not just how many numbers are missing. Every puzzle has exactly one answer.

Adaptive (the default) moves up after chat breezes through a puzzle with few wrong answers and no hints, and down after a struggle. The end screen says why, e.g. “Next: level 12 · Hard+ — ▲ up 1 (86% right, 1 hint)”.

Puzzle types: Classic, Diagonal (both diagonals have 1–9), Windoku (four extra shaded boxes), Center Dot (the nine box centres) and Asterisk (nine starred cells). Mix alternates classic with each twist.

QUESTIONS AT THE BAR
Do I need a bot or to log in with Twitch?

No. The board reads your chat the same way twitch.tv shows it to logged-out viewers: anonymously and read-only. It never posts in chat and never asks for a password or token.

I use GuildScribe's full stream theme. How do I fit it in?

The theme has a Sudoku on Stream scene (&scene=sudoku on the theme link, or pick it on GuildScribe's !overlays page). Pick Layout: GuildScribe theme window above, add the game below the theme in your sources, size it 1464 × 912 and place it at X 40, Y 112. The theme's torn edge overlaps it slightly; the layout leaves room for that.

Normal chat keeps setting off moves.

Open More options above and set a command prefix like !. Then only !B7 4 counts.

Will I lose the scores or the puzzle if OBS restarts?

No. The puzzle in progress, this puzzle's scores and the all-time leaderboard are saved inside OBS's browser. A paused game stays paused after a reload too.

The control page buttons do nothing.

Check that both sources come from the same place: both links from this page, or both file:/// paths from your download. Also make sure the game source is in a scene that's loaded, and that Shutdown source when not visible is unticked on the control page. The control page shows whether it can see the game.

The board says “disconnected”.

Check the channel name in the link (it's the name in your twitch.tv address). It reconnects by itself after a network blip. To check everything works without chat, use the Test it in your browser button above and type moves into the box.
