🛠️ The Workshop

Open the workshop

The workshop edits the site's projects, The Path So Far and every project's files, then commits the changes straight to GitHub. GitHub Pages publishes them a minute later.

  1. Make a fine-grained token on GitHub.
  2. Under Repository access, pick only the site's repo.
  3. Under Permissions → Contents, choose Read and write.
  4. Paste it below.

The token stays in this browser and only goes to api.github.com. Without "remember", it's forgotten when you close the tab. Without a token you can browse a public repo but not commit.
