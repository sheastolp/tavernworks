STREAM OVERLAYS

Overlays

Two OBS browser sources: a badge that sends viewers to tavernworks.dev, and a card that shows which project is on screen.

THE LINK BADGE

1Point viewers at tavernworks.dev

A small corner badge that stays on screen. Pick a corner and size, then copy the link into OBS.

THE PROJECT CARD

2Show which project you're using

A card with the project's icon, name and link. Leave it on Latest on the path and it follows whatever project changed last, or pick one. Make one source per project and switch them with your scenes.

ADD THEM TO OBS

3Browser sources

  1. In your scene, add a Browser source and paste a link as the URL.
  2. Set the size to 1920 × 1080 (or your canvas size). Everything but the badge is see-through.
  3. Put the badge and the card in different corners so they don't overlap.
