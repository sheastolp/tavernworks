THE IDEA

Most AI chat is a thin window onto someone else's server. Every message goes off to a data centre and gets logged somewhere you can't see.

This one lives at home. A retired Lenovo Yoga 730 runs headless Ubuntu with the lid shut, serving a large language model on nothing but its CPU. The chats stay on hardware I own.

CHAT FROM THE BROWSER

The browser chat is a lightweight, Open WebUI-style client that talks straight to Ollama over Tailscale. Nothing passes through this website: the page loads here, then your browser talks to the laptop directly. It only works from devices on the tailnet. The server address is saved in your own browser, never on this site.

  1. Give Ollama an HTTPS address on the tailnet

    This site is HTTPS, so browsers won't let it call plain http://. Tailscale can serve Ollama with a real certificate (turn on MagicDNS and HTTPS certificates under DNS in the Tailscale admin console first):

    sudo tailscale serve --bg 11434

    It prints an address like https://yoga.tail1234.ts.net. Only tailnet devices can open it.

  2. Let this site talk to Ollama

    Ollama only answers browser requests from sites it's told to trust:

    sudo systemctl edit ollama
# add these two lines, then save:
[Service]
Environment="OLLAMA_ORIGINS=https://tavernworks.dev"

sudo systemctl restart ollama

  3. Connect

    Open the chat, paste the address from step 1, hit Test connection, then Save. Add Open WebUI's address too and the Open Local AI button will take you straight there.

    If the browser asks to allow access to devices on your local network, allow it. A "403" means step 2 isn't in place yet.

FORGE YOUR OWN

Got an old laptop gathering dust? The basic recipe on Ubuntu is short. Check each project's docs for the current install steps.

1. Install Ollama and pull a small model

curl -fsSL https://ollama.com/install.sh | sh
ollama run llama3.2

2. Put Open WebUI in front of it (with Docker)

docker run -d -p 3000:8080 \
  --add-host=host.docker.internal:host-gateway \
  -v open-webui:/app/backend/data \
  --name open-webui --restart always \
  ghcr.io/open-webui/open-webui:main

3. Join it to your Tailscale network

curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up

Then open http://<machine-name>:3000 from any device on your tailnet, or SSH in to manage it. No ports opened to the internet.

QUESTIONS AT THE BAR
Can I use it?

It's a personal setup on my own private network, not a public service. The recipe above will get you your own.

Is it as good as ChatGPT?

No. Small models running on a laptop CPU can't match the big hosted ones. They're still handy for everyday questions, drafting and tinkering, and they're private.

Why a laptop?

It was already there. Laptops are quiet, sip power and come with a built-in battery backup, which makes them decent little home servers.

Why CPU only?

The laptop has no graphics card Ollama can use, so the processor does all the work. It's slower, but it proves you don't need fancy hardware to run AI at home.
