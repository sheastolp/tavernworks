Hushwave

An ambient sound player for Windows. Rain, fire and room tone to focus or chill to, and a prompt studio that makes a soundscape from a sentence.

THE IDEA

Most ambient sound apps are a browser tab full of ads, or a library you can't safely play on stream. Hushwave is a small, native Windows player with a library of original sounds that won't get a VOD muted.

Pick a sound, layer a couple more under it with Quick Mix, set a sleep timer and forget about it. When nothing in the library fits, type what you want to hear, like crackling fireplace with heavy rain and distant thunder or gentle stream with birdsong, and the prompt studio makes a seamless loop of it on your PC.

WHAT'S IN THE BOX
🎚️

Quick Mix

Layer up to three sounds under whatever's playing, each with its own volume. Rain over a fire over brown noise.

✨

Prompt studio

Describe it and Hushwave layers up to five sounds: rain, thunder, wind, fire, waves, a stream, crickets, birdsong, traffic, café murmur, a train, drones, chimes, pads and noise. Words like gentle, dark, cathedral or underwater shape it, a "Will layer" line shows what it heard, and every press gives a new variation.

🔁

Loops & sleep timer

Generated loops are 30 seconds, 1 minute or 2 minutes and repeat without a gap. Repeat one sound, play through the library, or stop at the end. The sleep timer stops everything after 15, 30, 60 or 90 minutes, with a live countdown.

📂

Your own files

Drag MP3, WAV, OGG, FLAC or M4A files onto the window. Search by name, click a tag to filter, and hide built-in tracks you don't want, with Undo if you change your mind.

🎥

OBS-friendly output

Send Hushwave to its own audio device so OBS can capture it on a separate track. A notice in the player says when sound isn't going to your default speakers, with a one-click Use default.

⌨️

Keys and media buttons

Space to play or pause, arrows to skip, M to mute, Ctrl+K or / to search. Keyboard media keys, headset buttons and the Windows media overlay work too.

🪶

Native and light

Built with Tauri, not Electron. A real Windows app with a small installer, no browser tab needed.

WHERE THE SOUND COMES FROM

🛠️ Offline generator DEFAULT

Layers the sounds your prompt names right on your PC, with seamless loops. No account, no network, and original audio you can stream.

🎙️ Freesound FREE KEY

Searches Freesound for a real CC0 recording that matches your prompt. Needs your own free Freesound API key. If a request fails, Hushwave falls back to the offline generator.

🤖 ElevenLabs PAID KEY

AI-generated sound effects from your prompt, using your own ElevenLabs API key and credits.

GET THE INSTALLER

Hushwave's installer is built by GitHub, not on your PC, so there's nothing to compile and no developer tools to install. You make your own copy of the files on GitHub, switch on its build, and download the installer it makes. All you need is a free GitHub account. The first time takes about 20 minutes, most of it waiting.

  1. Sign in to GitHub

    Sign in at github.com, or make a free account first. GitHub only lets signed-in people run builds and download them.

  2. Make your own copy (fork)

    Open github.com/sheastolp/Hushwave and click Fork near the top right. Leave the settings as they are and click Create fork.

    GitHub takes you to your copy at github.com/your-name/Hushwave. Do the rest of the steps there.

  3. Turn on GitHub Actions

    In your copy, click the Actions tab. GitHub keeps builds switched off on new copies, so you'll see "Workflows aren't being run on this forked repository". Click I understand my workflows, go ahead and enable them.

  4. Build the installer

    Still on the Actions tab, click Build Windows installer in the list on the left. Click the Run workflow button on the right, leave the branch on main, and click the green Run workflow.

    A new run appears after a few seconds (refresh if it doesn't). The yellow dot means it's building. The first build takes 10 to 15 minutes; later ones are faster. When it turns into a green check mark ✅, it's done. A red ✖ means the build failed; click Re-run jobs on the run, and if it fails again, ask in the Discord.

  5. Download the installer

    Click the finished green run, scroll to Artifacts at the bottom, and click hushwave-windows-installer. A zip file downloads.

  6. Unzip it

    Right-click the zip and choose Extract All. Inside are two installers; you only need one:

    • Hushwave_x.y.z_x64-setup.exe: use this one.
    • Hushwave_x.y.z_x64_en-US.msi: only for work PCs that require MSI installers.

  7. Run the installer

    Double-click the -setup.exe. If Windows says "Windows protected your PC", click More info → Run anyway. That shows up because the app isn't signed with a paid code-signing certificate, not because anything's wrong.

    When it finishes, open Hushwave from the Start menu. The version in the top-left corner (like v1.0.13) tells you which build you have.

Updating: on your copy's front page, click Sync fork → Update branch to pull in the newest changes. Then build and download again (steps 4 to 7) and run the new installer over the old one. Your settings stay.
Needs: Windows 10 or 11 with the Microsoft WebView2 runtime, which Windows 11 and up-to-date Windows 10 already have.
No Artifacts on an old run? GitHub deletes builds after a while. Just run the workflow again (step 4).
Costs nothing: builds on public copies are free on GitHub, and your copy is public like the original.
The README's setup guide covers first run, online sound sources and OBS too.
QUESTIONS AT THE BAR
How do I install it?

Make your own copy (fork) of Hushwave on GitHub, turn on Actions, run Build Windows installer, then download the installer it makes and run the -setup.exe. The step-by-step guide above walks through it. To update, run a newer installer over the old one and your settings stay.

Is it safe to play on stream?

The built-in library and the offline generator are original, so yes. Sounds you pull in from Freesound or ElevenLabs are under their licenses, not Hushwave's, so check them before you go live.

The app opens to a blank white window.

Hushwave draws its window with Microsoft Edge WebView2. Install or repair the WebView2 runtime and open it again.

How do I get it into OBS on its own track?

Install the free VB-Audio Virtual Cable and restart. In Hushwave's Preferences → Audio output, choose CABLE Input (click Show all devices by name if you only see generic names; Windows asks for the microphone once just to reveal them, and nothing is recorded). In OBS, add an Audio Input Capture for CABLE Output. To hear it yourself too, turn on Listen to this device for CABLE Output in Windows' recording devices.

I can't hear anything.

Open Preferences → Audio output and press Play test sound; it tells you which device it played through. If the player shows a yellow "Sound is going to…" notice, click Use default. Also check that Hushwave isn't muted in the Windows volume mixer or by its own mute button. If the device you picked was unplugged or removed, Hushwave now falls back to your default speakers on its own.

Mac or Linux?

Windows only for now. If you want it elsewhere, say so in the suggestion box below.
